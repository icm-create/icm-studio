Studio
Preencha a edição e as notícias à esquerda. À direita você tem duas saídas: o HTML pronto para colar no Gmail e o texto para postar no chat (com a capa para anexar separadamente).

Rascunho (backup automático)

Salva sozinho a cada poucos segundos numa planilha do Google (mesma lógica do ICM Studio v1), assim como o rascunho não se perde se a aba fechar. Configure a URL do Apps Script uma vez em "Configurar".

Edição

Suba o arquivo banner_icm_news.png (gerado junto com esta ferramenta) no GitHub Pages / portal ICM e cole aqui a URL pública. Enquanto isso, o caminho relativo já mostra a prévia certinha.
Este banner vai dentro do HTML do e-mail (cabeçalho). Não precisa ser anexado no chat.
square_icm_news.png — mesma identidade do banner, em formato quadrado. Anexe este arquivo junto sempre que postar o texto da ICM News no chat.
